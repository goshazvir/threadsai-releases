# ThreadPilot — релизы клиента

Здесь публикуются готовые к установке версии ThreadPilot. Каждая собирается
автоматически, проверяется на утечки и подписывается — вручную сюда ничего
не выкладывается.

## Установка

Одной командой в Терминале (macOS):

```bash
bash <(curl -fsSL https://threadpilot-self.vercel.app/install.sh)
```

Перед запуском скачайте файл настроек `threadsai.env` — в панели ThreadPilot:
**Настройки → Подключение → «Скачать threadsai.env»**. Установщик ищет его в
папке «Загрузки»; если файл лежит в другом месте, передайте путь:

```bash
bash <(curl -fsSL https://threadpilot-self.vercel.app/install.sh) /путь/к/threadsai.env
```

Установщик сам скачает свежий релиз отсюда, проверит подпись и настроит
запуск. Ни Git, ни доступ к нашему репозиторию для этого не нужны.

## Почему этот репозиторий публичный

Чтобы установка работала до того, как у человека появится учётная запись:
установщик скачивает архив раньше любой авторизации. Приватный репозиторий
означал бы раздачу токена доступа всем подряд — то есть ту же публичность,
только с лишним шагом и риском утечки токена.

В архиве нет ничего, чего не было бы на компьютере каждого пользователя:
расширение для браузера и локальная служба запуска. Серверный код, тексты
запросов к модели и ключи остаются на сервере и в архив не попадают —
это проверяется автоматически при каждой сборке, и сборка падает, если
в архив попало лишнее.

## Проверка подлинности

Установщик проверяет подпись сам и откажется ставить изменённый архив.
Проверить вручную:

```bash
minisign -Vm threadsai-client-<версия>.zip \
         -x threadsai-client-<версия>.zip.minisig \
         -P RWTbdwMhi7xU79V3VYUj5uFbS1GdTaEyl7BvEkt2OvfN6Jj/LaPrvp+B
```

Ответ `Signature and comment signature verified` означает, что архив собран
нами и с тех пор не менялся. Любой другой ответ — файл трогали, ставить его
нельзя.

Контрольная сумма — в файле `.sha256` рядом с архивом:

```bash
shasum -a 256 -c threadsai-client-<версия>.zip.sha256
```

## Что в каждом релизе

| Файл | Что это |
|---|---|
| `threadsai-client-<версия>.zip` | сам продукт |
| `...zip.minisig` | подпись |
| `...zip.sha256` | контрольная сумма |

Файлы «Source code», которые GitHub добавляет автоматически, — это
содержимое **этого** репозитория, то есть один лишь данный README.
Исходного кода продукта в них нет.
